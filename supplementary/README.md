# Supporting information: autonomy modes and validation depth in disaster SAR robotics (2025–2026)

| File | Content |
|---|---|
| `screening_log.csv` (S1) | All 125 unique records screened: record ID, title, decision, criteria violated, and the logged reason. The five removed duplicate copies (IDs 12, 86, 102, 108, 130) are not listed. |
| `S2_extraction_table.csv` | The 39 included studies: the 18 extraction fields, clean categories, sensor flags, strict and lenient validation, human role modeled, environmental-realism limitation (author-stated and broad readings), FA cluster, and VDR quality score (vd, rp, stat). Every coded cell carries a `*_page` column giving the PDF page position of its evidence. |
| `S3_classification_rationale.md` | Per-study rationale for mode, validation, human role and realism coding. |
| `coding_manual.md` (S4) | Decision rules for the autonomy/HRI modes, with worked boundary cases, for human second coders. |
| `S5_analysis_output.md` | Every table and statistic reported in Section III, regenerated by `scripts/analysis.py`. |
| `S6_reliability_blind_codes.csv` | The post hoc AI blind re-coding of mode (Methods II-G). This is **not** human inter-rater agreement. |
| `S7_function_autonomy.csv` | Post hoc AI-assisted per-function coding: who holds acquisition, analysis, decision and action (machine, shared or human) for each study. Each code has a page reference and a short evidence snippet (Methods II-G; Table XX). |
| `human_second_coder_sheet.csv` | A blank, shuffled coding sheet for an independent human second coder. |
| `PRISMA_2020_checklist.md`, `PRISMA-S_checklist.md` | Completed reporting checklists. |
| `search_protocol.md` | The search actually run, and a fully specified supplementary database-search protocol. |
| `scripts/` | `analysis.py` (all statistics), `make_figures.py` (Figs. 4–7), `make_prisma_v2.py` (Fig. 2), `reliability_stats.py` (κ, AC1). The scripts expect the CSVs under `data/`. Copy `S2_extraction_table.csv` to `data/extraction_table.csv` and `S6_reliability_blind_codes.csv` to `data/reliability_blind_codes.csv`, then run `python scripts/analysis.py` (Python 3, numpy, scipy, matplotlib). |

Record IDs refer to the authors' 130-record catalog. AI tools were used in identification, extraction, analysis scripting and drafting; see the AI-use statement in the manuscript.
